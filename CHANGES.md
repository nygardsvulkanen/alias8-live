# Alias8 – changes

- 2026-11-24: Repo started: README with the planned layout, PLAN.md, CLAUDE.md, MIT license. No script yet.
- 2026-11-24: Phase 1: the `Alias8` script – Live's coloured box (follows the selected track), faders = volume, master fader, bank 1 knobs = Send A / B, top buttons tap = select / hold = arm, bottom buttons tap = mute / hold = solo, track colours on the buttons, bank switching. 18 tests against a fake Live (`tests/`). Not yet tried on hardware.
- 2026-11-24: The encoder scrolls Live's coloured box (press it on the Alias 8 for CC mode, then turn; CC 42 relative, `SCROLL_STEP`). The box now follows only a newly selected track, so scrolling isn't undone. 22 tests.
- 2026-11-24: Encoder scrolling confirmed on Daniel's Alias 8 in Live 12.4.
- 2026-11-24: Phase 2: bank 2 = pan / Send C (`BANK2_SEND`), bank 3 = macros 1-16 of the selected track's first rack with pickup (`MACRO_PICKUP`), unmapped and locked macros skipped, status bar shows the macro and its value. 30 tests. Not yet tried on hardware.
- 2026-11-24: Banks 2 and 3 confirmed on Daniel's Alias 8 in Live 12.4.
- 2026-11-24: Zero configuration: at start-up the script asks the Alias 8 for its colour map (cmd 34) and encoder style (cmd 17), sends its own if they differ (factory colours were wrong; the factory encoder press only changed bank), and puts the originals back on disconnect. Nothing is saved. Settings messages no longer fill Live's log as "unknown sysex". 36 tests.
- 2026-11-24: Fix: scrolling past the selected track made the box jump back and forth (the buttons flickered between two colour sets). The script compared the selected track with `is`, but Live hands out a new object on every read, so every tick looked like a new selection. The fake Live now does the same, and all 37 tests pass with it.
- 2026-11-24: Zero configuration and the scroll fix confirmed on Daniel's factory-reset Alias 8 in Live 12.4.
- 2026-11-24: The script no longer changes the encoder (cmd 17 is the encoder type absolute/relative, not the press toggle – setting it made the display show 01 instead of CC). It reads the encoder's CC (cmd 16) and type (cmd 17) from the Alias 8 and scrolls with both absolute (factory: one track per message, by direction) and relative. Only the colour map is still changed temporarily. 39 tests.
- 2026-11-24: Fix: wrong button colours for a few seconds when Live starts. The script now sends its colour map right after asking for the controller's own (the answer still gives the original, sent back on disconnect) and lights no button before that. 41 tests, including the order of what is sent.
- 2026-11-24: `DEBUG` setting (off): writes encoder messages and the Alias 8's settings to Live's Log.txt. The Alias 8's ACK after the colour map no longer shows up in the log as "unknown sysex". 43 tests.
- 2026-11-24: Checked on hardware with DEBUG: a factory Alias 8 sends absolute CC 42 in steps of 8 (16 clicks from 0 to 127), and the box follows it correctly. README explains the limit (relative or a lower Speed A for more).
- 2026-11-24: `PAGE_ORDER` at the top of settings.py sets which page is on which bank ("sends", "pan", "macros"; reorder, leave out or repeat, up to 15 banks). `BANK1_SENDS` / `BANK2_SEND` are now `SENDS_PAGE` / `PAN_PAGE_SEND`. A typo in PAGE_ORDER shows in Live's status bar. The status bar names the page on a bank change. 49 tests.
- 2026-11-25: Fix: the factory colours didn't come back after Live closed. The Alias 8 never answered the question about its colour map (it was followed at once by other sysex), so the script didn't know what to put back. Now it asks one setting at a time (colour map first, asking again if there is no answer), sends its own map only after the answer, and lights the buttons then. The fake Live now has a fake Alias 8 that answers like the real one. 49 tests.
